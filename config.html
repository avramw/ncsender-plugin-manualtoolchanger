Events

Pre Tool Change

G-code executed at the very start of the tool change sequence, before any other operations. Runs in the units the program is using (G20/G21), not always millimetres — so put an explicit G20 or G21 in the snippet if it contains coordinates. Units and distance mode are restored afterwards, so anything modal you set here cannot leak into the rest of the job.

Post Tool Change

G-code executed at the very end of the tool change sequence, after all operations complete. Runs in the units the program is using (G20/G21), not always millimetres — so put an explicit G20 or G21 in the snippet if it contains coordinates. Units and distance mode are restored afterwards, so anything modal you set here cannot leak into the rest of the job.

Pre TLS

G-code executed right before the tool-length probe starts, once the spindle is parked over the tool setter at the probe-start Z. Use it to switch on a wired tool setter (e.g. M64 P1), fire an aux output for dust collection / air blast, or dwell before probing.

Post TLS

G-code executed immediately after the probe retracts, before the tool length offset is applied. Use it to switch the tool setter back off (e.g. M65 P1), close an aux output, or restore dust collection.

Abort Event

G-code executed when the abort button is pressed during tool change. Runs before soft reset.
